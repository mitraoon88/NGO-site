# `apps/web/brand/tokens.css` — generated mirror

A one-line `@import` wrapper so the app never resolves outside its own root:

```css
@import "../../../brand/tokens.css";
```

**Edit `a2-foundation/brand/tokens.css` instead** — that file is the single source of truth.
`npm run check:tokens` fails the build if the preset and that file ever disagree.
